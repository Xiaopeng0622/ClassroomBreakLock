# 教室多媒体课间锁 (ClassroomBreakLock)

一个给学校教室多媒体机用的**课间锁屏**应用模板。核心目标：上课时段把机器锁住，课间/课前自动放开，老师用 U 盘、密码或手机动态码解锁。

技术栈：**WPF (.NET 8)** 单文件桌面应用，无第三方依赖。

---

## ⚠️ 两个「刻意的设计」——不要当成缺陷去修

这两条是原模板作者（DSH）有意为之，改之前先想清楚：

### 1. 首次运行默认开启「测试模式」

`AppConfig.TestMode` 默认 `true`，即**默认不按作息表自动锁屏**。

原因：默认配置里**一个认证方式都没配**，如果一启动就按时锁上，配置者会被关在锁屏外面、连设置都进不去（先有鸡还是先有蛋）。

> **正式部署前必须去设置里取消勾选「测试模式」**，否则课间根本不会自动锁。
> 另：测试模式下用手动方式锁上后，调度不会自动解开；ClassIsland 同步事件在测试模式里也只弹气泡、不改变锁屏状态。

### 2. `app.manifest` 默认 `asInvoker`

模板阶段故意不要求管理员权限，方便直接双击运行测试。

后果：`asInvoker` 下无法压盖那些**以管理员权限运行**的程序（它们会盖在锁屏之上）。

> 要真正压住管理员权限的程序，需要把 `app.manifest` 里的 `requestedExecutionLevel`
> 从 `asInvoker` 改成 `requireAdministrator`。改了以后每次启动都会弹 UAC。

## 三、解锁判定的优先级

`ScheduleEngine.Evaluate()` 从上往下匹配，命中即返回：

1. 总开关关闭 → **解锁**
2. 命中某个日期的覆盖规则（放假/调休）→ 按覆盖
3. 该星期未启用 → **解锁**
4. 正处于某节课时段内 → **锁定**（若该时段 `LockDuring=false` 则解锁）
5. **处于"课前 N 分钟"窗口 → 解锁** ← 你要的 2-b
6. 处于两节课之间的课间 → 锁定（可配置为课间不锁）
7. 当天所有课已结束 → **解锁**
8. 第一节课开始之前 → **解锁**

另外有一条**独立的解锁通道**：认证通过 / 点击"下课"按钮 / 托盘强制解锁。
这三种都会写审计日志。

## 四、U 盘认证的双重绑定

一把钥匙 = **卷序列号** + **密钥文件内容哈希**，两者必须同时对上：

```
登记的钥匙： SN=1A2B-3C4D  +  文件 breaklock.key 内容哈希 = a3f1...
插入的 U 盘： SN=1A2B-3C4D  +  breaklock.key 哈希       = a3f1...  → ✓ 通过
             SN=5E6F-7G8H  +  同一个 breaklock.key       = a3f1...  → ✗ 拒绝（盘不对）
             SN=1A2B-3C4D  +  文件被改过                  = 9c2d...  → ✗ 拒绝（内容不对）
```

所以**把密钥文件拷到别的 U 盘没用**，这正是你要的"识别对应单一 U 盘身份"。

**多把钥匙**：设置界面「登记为新钥匙」可以登记任意多把（班主任一把、年级组长一把、备用一把），任意一把都能解锁。

> **关于硬件序列号**：模板用的是**卷序列号**（`GetVolumeInformation`），格式化会变但不需要管理员权限。如果你需要更硬的**物理设备序列号**（`IOCTL_STORAGE_QUERY_PROPERTY` 取 USB 描述符里的 iSerialNumber），见下方「正式部署」——那个需要管理员权限，且部分廉价 U 盘根本不写入该字段。

## 六、扩展功能（你可以自行取舍）

1. **应急码** — 忘带 U 盘又没手机时的兜底通道。生成一次性的 `XXXX-XXXX-XXXX` 码，**用一次自动作废并留痕**。
2. **审计日志** — 按天分文件，谁在什么时候、用什么方式解锁/解锁失败全部记录，默认保留 90 天。
3. **看门狗防退出** — 另起一个自身进程守护，主进程被结束就自动重启。*（已在实测中验证生效）*
4. **日期覆盖** — 调休、考试、临时放假不用改作息表本体。
5. **课前提前解锁可按节次覆盖** — 比如早读提前 10 分钟开、普通课提前 2 分钟。
6. **截屏/投屏保护** — 可把锁屏窗口从 `WDA_EXCLUDEFROMCAPTURE` 中排除（Win10 2004+）。
7. **悬浮按钮智能淡出** — 鼠标不动就淡化到 25%，不挡课件；靠近就恢复。
8. **单实例保护** — 防止重复启动互相抢置顶。
9. **原子写配置** — 先写临时文件再替换，掉电不会写坏配置；每次保存留 `.bak`。
10. **全部认证方式的开关独立** — 可以只启用 U 盘，也可以三种全开。

## 八、正式部署到教室机器

### 1. 打开提权

编辑 `app.manifest`，把：

```xml
<requestedExecutionLevel level="asInvoker" uiAccess="false" />
```

改成：

```xml
<requestedExecutionLevel level="requireAdministrator" uiAccess="false" />
```

**为什么**：不加管理员权限时，如果教室里跑着任何以管理员身份运行的程序，它的窗口会盖在锁屏之上。加了之后才能压住它们。

### 2. 关闭测试模式

设置界面「常规」→ 取消勾选「测试模式」→ 保存。**这一步不做的话课间根本不会自动锁。**

### 3. 发布

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

### 4. 开机自启

任务计划程序 → 新建任务 → 触发器「登录时」+「工作站解锁时」 → 操作指向发布的 exe → 勾选「使用最高权限运行」。

## 九、已知限制 / 注意事项

1. **Ctrl+Alt+Del 无法用键盘钩子屏蔽** — 这是 Windows 的 SAS 安全序列，设计上就不允许拦截。要挡住它需要组策略或替换 GINA/凭证提供程序，超出模板范围。学生按了之后会看到锁屏界面，但**在没有正确凭据的情况下进不去桌面**。
2. **任务管理器** — 提权运行 + `Ctrl+Shift+Esc` 已屏蔽，可以挡住。但如果学生已经知道管理员密码，什么锁都拦不住——这类方案的定位是"防随手乱动"，不是"防恶意破解"。
3. **截屏保护** — `WDA_EXCLUDEFROMCAPTURE` 需要 Win10 2004 及以上；更低版本自动退回 `WDA_MONITOR`。
4. **卷序列号会被格式化改变** — 重装/格式化 U 盘后需要重新登记钥匙。
5. **看门狗是"重启"不是"防杀"** — 对方如果在极短时间内连续结束主进程和看门狗进程，仍然能突破。要更硬需要做成 Windows 服务。
6. **时间判定依赖系统时钟** — 把系统时间改掉就能绕过。正式环境建议在组策略里禁止普通用户修改时间。
7. **首次运行默认测试模式** — 切记正式部署前关掉。
