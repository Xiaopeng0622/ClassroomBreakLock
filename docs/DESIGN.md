# 设计风格约定

> 本文档记录本项目的视觉语言与风格约定，改界面前**先读这里**。

## 一句话概括

**极简，但有创意。**

底色克制到近乎无装饰，亮点少而精准。

用户原话：「极简但有创意」——并明确要求记住这个类型。

---

## 风格定位

Fluent / WinUI / ClassIsland 取向。不追求花哨，追求**干净的秩序感 + 少量出彩的点缀**。

参照对象：ClassIsland 的界面。

---

## 具体规则

### 描边与留白
- **无重边框、无投影**（弹窗除外——弹窗用柔和投影是允许的）
- 描边极浅：`#E5E5E5` / `#EBEBEB`，几乎看不见但能起到分隔作用
- 大留白。宁可空一点，也不要挤

### 圆角（克制）
| 用途 | 半径 |
|---|---|
| 卡片 | 8px |
| 控件 | 6px |
| 信息条 / 标签 | 999px（药丸形） |

⚠️ 不要用 20px+ 的大圆角，那是另一套风格。

### 分层色（浅色面）
| 层 | 色值 | 用途 |
|---|---|---|
| Layer0 | `#F3F3F3` | 窗口底（Mica 近似） |
| Layer1 | `#FFFFFF` | 卡片 |
| Layer2 | `#F9F9F9` | 卡片内次级面 |

### 文字三级色
| 级别 | 色值 | 用途 |
|---|---|---|
| 主 | `#1B1B1B` | 正文、标题 |
| 次 | `#5D5D5D` | 说明文字 |
| 弱 | `#8A8A8A` | 提示、占位 |

### 强调色
- 主强调：`#0067C0`（Win11 蓝），hover `#1975C5`
- 浅底：`#EFF6FC`
- **天依蓝渐变**：`#66CCFF` → `#2E90D9`（135° 线性）

  ⚠️ **这个渐变是"创意"的主要落点**，只用于关键按钮底 / 图标底 / 锁屏页光晕，不要到处用。

- 语义色：危险 `#C42B1C`、警告 `#9D5D00`、成功 `#0F7B0F`

### 深色面（锁屏页）
| 用途 | 色值 |
|---|---|
| 底 | `#0F1115` |
| 面 | `#1B1D22` |
| 次级面 | `#26282E` |
| 描边 | `#2E3138` |
| 主文字 | `#F2F4F7` |
| 次文字 | `#A5ACB8` |
| 弱文字 | `#767D89` |

锁屏页背景用渐变 `#141A26` → `#0B0D12`，左上角叠一层**淡淡的**天依蓝径向光晕。

### 布局
- 设置页：**左侧导航 + 右侧卡片**，不要用 TabControl
- 弹窗：用 `AppDialog` 的自绘圆角窗口，**不要用系统 MessageBox**（直角老样式，跟 Win11 界面放一起很掉价）

### 字体与动效
- 界面：`Microsoft YaHei UI, Segoe UI`
- 等宽：`Consolas, Cascadia Mono, monospace`
- 缓动：`CubicEase` / `EaseOut`

---

## 怎么理解"极简"与"创意"的配比

| | 体现在 |
|---|---|
| **极简** | 克制圆角、极浅描边、大留白、无多余装饰、三级文字色 |
| **有创意** | 天依蓝渐变点缀、深色锁屏页的光晕、药丸形信息条、自绘圆角弹窗 |

**底色极简，亮点少而准。**

两个反模式：
- ❌ 为了"创意"堆砌效果 → 变花哨
- ❌ 只做极简不敢点缀 → 变寡淡
