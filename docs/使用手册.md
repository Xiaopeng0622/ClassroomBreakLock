## 一、这是什么

一个给**教室多媒体机**（讲台电脑）用的**课间锁屏**程序。

**它做什么：**

- 按你配置的作息表，**上课时段自动锁屏**，课间和课前自动放开
- 课前可提前 N 分钟解锁（让老师有时间开课件）
- 下课后延迟几秒再上锁（不用老师盯着表）

**老师怎么解锁：** 三种方式，任选其一

| 方式 | 说明 |
|---|---|
| **U 盘** | 插上登记过的 U 盘，自动识别。拔走即失效 |
| **密码** | 键盘输入密码 |
| **动态码** | 手机验证器（Google/微软/1Password 等）上的 6 位码，每 30 秒变一次 |

还有一条兜底通道：**应急码**（一次性，用完作废）。

**技术栈：** WPF (.NET 8)，单文件桌面程序，**无任何第三方依赖**。

## 二、五分钟跑起来

### 1. 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 1903 及以上 / Windows 11 |
| 运行时 | .NET 8 Desktop Runtime（[下载](https://dotnet.microsoft.com/download/dotnet/8.0)） |
| 权限 | 测试阶段**不需要**管理员；正式部署建议管理员（见[第九节](#九正式部署到教室机器)） |

### 2. 编译

```powershell
cd src\ClassroomBreakLock
dotnet run
```

或者直接发布一个 exe：

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

### 3. 首次运行会看到什么

程序启动后**不会锁屏**——这是**刻意的设计**。

原因：默认配置里一个认证方式都没配。如果按作息表一上来就把屏幕锁了，你会被关在外面，**连设置都进不去**（先有鸡还是先有蛋）。

> ⚠️ **正式部署前必须回到设置里取消勾选「测试模式」**，否则课间永远不会自动锁。

首次运行的正确操作顺序：

```
① 启动程序  →  右下角出现「下课」悬浮按钮，托盘出现图标
② 双击托盘图标（或双击悬浮按钮）→ 打开设置
③ 去「认证」页：配好至少一种解锁方式（U 盘 / 密码 / 动态码）
④ 去「作息表」页：确认或修改上课时间
⑤ 回到「常规」页：取消勾选「测试模式」→ 保存
⑥ 右键托盘 →「立即锁定」→ 试一遍解锁方式
```

### 4. 想快速回到不锁的状态

删掉配置文件再重启：

```
C:\ProgramData\ClassroomBreakLock\config.json
```

删掉后重启会回到默认的「测试模式」。

## 三、三种解锁方式怎么配

打开设置 → 左侧「认证」页。三种方式可以同时启用，也可以只启用一种。

### 3.1 U 盘认证（推荐，老师最省事）

**原理：** 一把钥匙 = **U 盘的卷序列号** + **盘内密钥文件的内容哈希**，两者必须同时匹配。

```
登记的钥匙： SN=1A2B-3C4D  +  breaklock.key 内容哈希 = a3f1...
插入的 U 盘： SN=1A2B-3C4D  +  breaklock.key 哈希       = a3f1...  → ✓ 通过
             SN=5E6F-7G8H  +  同一个 breaklock.key       = a3f1...  → ✗ 拒绝（盘不对）
             SN=1A2B-3C4D  +  文件被改过                  = 9c2d...  → ✗ 拒绝（内容不对）
```

**所以把密钥文件拷贝到别的 U 盘是没用的**，必须是登记过的那把物理盘。

**配置步骤：**

1. 插上要做钥匙的 U 盘
2. 设置 →「认证」→ 点「刷新已插入 U 盘」
3. 在列表里选中你的盘 → 点「登记为新钥匙」
4. 程序会在 U 盘根目录写一个 `breaklock.key` 文件（**别删它**）

**可以登记多把**：班主任一把、年级组长一把、备用一把，任意一把都能解锁。

> **注意**：识别用的是**卷序列号**（格式化后会变），不是物理设备序列号。所以格式化 U 盘后需要重新登记。

### 3.2 密码认证

设置 →「认证」→「密码认证」：

- 设一个密码（**不存明文**，用 PBKDF2-SHA256 加 12 万次迭代 + 随机盐存储）
- 可选填「提示语」，会显示在锁屏页帮老师回忆

### 3.3 动态码（TOTP）

设置 →「认证」→「TOTP 动态码」：

1. 点「生成密钥」
2. 用手机上的验证器 App 扫码（或手动录入那串密钥）
   - 支持：Google Authenticator、Microsoft Authenticator、1Password、Bitwarden 等
3. 锁屏时输入 App 上显示的 6 位数字

符合 RFC 6238 标准，**已通过官方 6 组测试向量**。

### 3.4 应急码（兜底）

设置 →「认证」→「应急码」→ 生成一个 `XXXX-XXXX-XXXX` 格式的码。

- **用一次就作废**，并且会留下审计记录
- 适合「忘带 U 盘 + 手机没电」的极端情况
- 建议生成后抄在办公室抽屉里

## 四、设置项全表

设置界面是**左侧导航 + 右侧卡片**的结构。下面是全部可配置项。

### 常规 / 基本

| 项 | 默认值 | 说明 |
|---|---|---|
| **测试模式** | **开** | 开启时不自动锁屏。⚠️ **正式部署前必须关掉** |
| 教室名 | 高一(3)班 | 显示在锁屏页和日志里，便于远程区分多台机器 |

## 五、作息表怎么填

### 默认作息（开箱即用）

程序自带一套标准中学作息，周一~周五启用：

| 节次 | 时间 | 锁屏 |
|---|---|---|
| 早读 | 07:30 – 07:55 | 否 |
| 第 1 节 | 08:00 – 08:45 | 是 |
| 第 2 节 | 08:55 – 09:40 | 是 |
| 第 3 节 | 10:00 – 10:45 | 是 |
| 第 4 节 | 10:55 – 11:40 | 是 |
| 午休 | 11:40 – 13:30 | 否 |
| 第 5 节 | 13:30 – 14:15 | 是 |
| 第 6 节 | 14:25 – 15:10 | 是 |
| 第 7 节 | 15:30 – 16:15 | 是 |
| 第 8 节 | 16:25 – 17:10 | 是 |
| 晚自习 | 19:00 – 21:00 | 是 |

「锁屏」列 = 否 的时段（早读、午休）**不会把屏幕锁上**，但依然算作息表里的一段时间。

### 判定优先级

程序按下面的顺序从上往下判断，命中即返回：

1. 总开关关闭 → **解锁**
2. 命中某个日期的覆盖规则（放假/调休）→ 按覆盖规则
3. 该星期未启用 → **解锁**
4. 正处于某节课时段内 → **锁定**（该时段若勾了「不锁屏」则解锁）
5. 处于课前 N 分钟窗口 → **解锁**（这就是「课前提前解锁」）
6. 处于两节课之间的课间 → **锁定**（可在设置里改成课间不锁）
7. 当天所有课已结束 → **解锁**
8. 第一节课开始之前 → **解锁**

### 时间边界

时段是**左闭右开**的：`[开始, 结束)`

- 08:00:00 → 算在上课
- 08:45:00 → 算下课的瞬间（不算在上课）

## 六、批量导入课表

设置 →「作息表」页可以导入现成的课表，不用一节一节手填。

### 支持格式

| 格式 | 说明 |
|---|---|
| **YAML** | 推荐。直接吃 ClassIsland / CESE 导出的 `subjects` + `schedules` 结构，一次铺满整周 |
| **Excel (.xlsx)** | 每行需要含两个时间 |
| **CSV / TXT** | 同上 |
| **直接粘贴** | 从 Excel 里复制一片区域，粘进对话框 |

### 文本格式要求

每行至少要有**两个时间点**，例如：

```
第1节 08:00 08:45
第2节 08:55 09:40
第3节 10:00 10:45
```

时间分隔符很宽松，下面这些写法都认：

- `08:00 08:45`
- `8:00-8:45`
- `08:00~08:45`
- `08:00--08:45`

### 导入后

- 带星期信息（YAML）→ 直接铺满整周
- 不带星期信息 → 填到当前编辑的那一天，然后可以点「复制到工作日」

导入前会先跑一遍**本地解析**；解析不出东西时会提示检查格式。

## 七、特殊的日期（放假 / 调休）

设置 →「日期覆盖」页，加一条即可：

| 日期 | 锁定 | 备注 |
|---|---|---|
| 2026-10-01 | 否 | 国庆放假，不锁屏 |
| 2026-09-28 | 是 | 周日调休上课，强制锁 |

- **锁定 = 否** → 这天完全不上锁（放假）
- **锁定 = 是** → 这天按作息表正常锁（调休上课）

> 覆盖规则**优先于**星期设置。所以「周日调休上课」就靠这个实现。

## 八、接 ClassIsland 自动上课下课

如果教室里用了 [ClassIsland](https://github.com/ClassIsland/ClassIsland) 这类课表软件，可以让它**直接驱动**本程序，不必两边各配一份作息表。

### 原理

本程序在本机开一个 **HTTP 端口（默认 8731，只绑 127.0.0.1，不对外暴露）**，
ClassIsland 在上下课时各请求一个 URL 即可。

### 配置步骤

1. 本程序设置 →「ClassIsland 状态同步」→ 勾选「启用本地接收端口」
2. 端口保持 8731（或改成你要的）
3. 可选：填一个令牌（填了之后请求必须带令牌）
4. 保存

### 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| `GET` | `/state` | 查询当前状态与最近一次事件（浏览器直接打开即可，用来确认通没通） |
| `GET`/`POST` | `/class/start` | 上课（可带 `?subject=数学`） |
| `GET`/`POST` | `/class/end` | 下课 |
| 别名 | `/start`、`/class/begin` | 同「上课」 |
| 别名 | `/end`、`/class/finish` | 同「下课」 |

**带令牌**（如果配了）：

- `?token=你的令牌`
- 或请求头 `X-Auth-Token: 你的令牌`

令牌不对返回 `401`，路径不对返回 `404`（并附上可用路径列表）。

### 在 ClassIsland 里怎么配

ClassIsland →「自动化」→ 建两条规则：

```
上课时  → 运行程序 → curl.exe -s http://127.0.0.1:8731/class/start?subject=课程名
下课时  → 运行程序 → curl.exe -s http://127.0.0.1:8731/class/end
```

### 两个行为开关

设置里可分别控制：

- **收到「上课」事件时立即上锁**（默认开）
- **收到「下课」事件时立即解锁**（默认开）

## 九、正式部署到教室机器

### 1. 打开管理员权限

编辑 `src/ClassroomBreakLock/app.manifest`，把：

```xml
<requestedExecutionLevel level="asInvoker" uiAccess="false" />
```

改成：

```xml
<requestedExecutionLevel level="requireAdministrator" uiAccess="false" />
```

**为什么要改：** 不加管理员权限时，如果教室里跑着任何以管理员身份运行的程序，它的窗口会盖在锁屏之上。加了之后才能压住它们。代价是每次启动会弹一次 UAC。

> 默认 `asInvoker` 是为了让你能直接双击测试，**不是缺陷**。

### 2. 关闭测试模式

设置 →「常规」→ 取消勾选「测试模式」→ 保存。

**这一步不做，课间根本不会自动锁。**

### 3. 发布

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

产物在 `bin\Release\net8.0-windows\win-x64\publish\`。

### 4. 设置开机自启

用「任务计划程序」：

1. 新建任务
2. 触发器：**登录时** + **工作站解锁时**
3. 操作：指向发布的 exe
4. 勾选 **「使用最高权限运行」**

### 5. 部署后自检

打开设置 →「安全」→「运行状态自检」面板，确认：

- 置顶 = 正常
- 键盘钩子 = 正常
- 看门狗 = 正常

## 十、日常使用（老师视角）

### 上课时

到点自动锁屏。屏幕上是锁屏页，有四个可切换的解锁页签：**U 盘 / 密码 / 动态码 / 应急码**。

### 解锁

| 方式 | 操作 |
|---|---|
| U 盘 | 插上登记过的 U 盘，自动识别 |
| 密码 | 切到「密码」页，输入 |
| 动态码 | 切到「动态码」页，输入手机上的 6 位数字 |
| 应急码 | 切到「应急码」页，输入一次性码 |

### 课间

按作息表自动解锁（课间会放开）。

### 右下角的「下课」按钮

这个按钮是**主动上锁**用的，不是解锁。

点击后的流程：

```
点击「下课」
   │
   ├─ 第一层：确认要下课吗？            ← 所有情况都会弹
   │     └─ 取消 → 结束
   │
   ├─ 检测：现在是否处于上课时段？
   │
   ├─ 不在上课时段 ────────────────────────→ 立即锁屏
   │
   └─ 在上课时段
         └─ 第二层：确认在上课时间下课吗？   ← 红色危险样式
               ├─ 取消 → 结束
               └─ 确认 → 立即锁屏
```

**为什么要多一层：** 上课时间点「下课」是反常操作（正常是老师下课离开时才点），大概率是误触。多一层红色确认，避免上课上一半点错把屏幕锁了。

**按钮的其他行为：**

- 鼠标移上去恢复全亮
- 鼠标静止 8 秒自动淡化
- 可以拖到任意位置，拖到屏幕边缘会吸附并缩成小圆点
- 锁屏期间按钮会**自动隐藏**（已经没用了）

### 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + Shift + K` | 紧急解锁（测试模式下直接解锁；正式模式需要认证） |

### 托盘菜单（右键图标）

- 立即锁定
- 解除锁定（先确认，再认证）
- 设置（需要认证）
- 查看日志
- 退出

**所有打开设置的入口都要先过认证**：托盘双击/菜单、悬浮按钮双击、锁屏页的「进入设置」按钮。

> **例外**：如果一个认证方式都没配置，认证门会**直接放行**并提示去配置。这是刻意的——否则你会被永久锁在设置外面，连配置的地方都进不去。配好任意一种认证后，这个后门自动关闭。

### 零认证时禁止锁屏（防自锁保护）

只要检测到**一种认证方式都没配置**，所有上锁入口都会被拦截：

| 入口 | 零认证时 |
|---|---|
| 悬浮「下课」按钮 | ✗ 拦截 |
| 托盘「立即锁定」 | ✗ 拦截 |
| 自动调度（作息表到点） | ✗ 拦截 |
| ClassIsland 上课事件 | ✗ 拦截 |

拦截时会弹窗说明原因，并提供「去配置」按钮。**这是防「把自己关在门外」的最后一道保险。**

| 模式 | 路径 |

默认在 `%ProgramData%\ClassroomBreakLock\logs`，**按天分文件**。

记录内容：谁在什么时候、用什么方式解锁 / 解锁失败，全部留痕。

### 想恢复出厂设置

删掉 `config.json` 重启即可。

## 十二、出问题怎么查

### 「课间根本不锁」

**最常见原因：测试模式还开着。**

设置 →「常规」→ 取消勾选「测试模式」→ 保存。

### 「锁屏压不住某个程序」

教室里有以**管理员权限**运行的程序。按[第九节第 1 步](#1-打开管理员权限)把 `app.manifest` 改成 `requireAdministrator`。

### 「设置打不开 / 一直要求认证」

- 检查是否配了至少一种认证方式
- 如果忘了密码又没带 U 盘 → 用应急码，或删 `config.json` 回到测试模式

### 「U 盘插上不认」

- 卷序列号会因为**格式化**而改变 → 需要重新登记
- 确认 U 盘里的 `breaklock.key` 没被删掉

### 「悬浮按钮不见了 / 位置不对」

- 设置 →「安全」→ 打开「详细调试日志」，日志里会有定位信息
- 检查「目标显示器」是不是指定了一块已经拔掉的屏
- 勾上「找不到屏时回落主屏」

### 「想确认程序是不是活着」

托盘图标还在 = 进程正常。或者设置 →「安全」→「运行状态自检」。

## 十三、已知限制

1. **`Ctrl+Alt+Del` 无法用键盘钩子屏蔽** — 这是 Windows 的 SAS 安全序列，设计上就不允许拦截。要挡住它需要组策略或替换凭证提供程序，超出本项目范围。学生按了之后会看到锁屏界面，但**在没有正确凭据的情况下进不去桌面**。

2. **任务管理器** — 提权运行 + `Ctrl+Shift+Esc` 已屏蔽，可以挡住。但如果学生已经知道管理员密码，什么锁都拦不住。这类方案的定位是**「防随手乱动」，不是「防恶意破解」**。

3. **截屏保护** — `WDA_EXCLUDEFROMCAPTURE` 需要 Win10 2004 及以上；更低版本自动退回 `WDA_MONITOR`。

4. **卷序列号会被格式化改变** — 重装/格式化 U 盘后需要重新登记钥匙。

5. **看门狗是「重启」不是「防杀」** — 如果在极短时间内连续结束主进程和看门狗进程，仍然能突破。要更硬需要做成 Windows 服务。

6. **时间判定依赖系统时钟** — 把系统时间改掉就能绕过。正式环境建议在组策略里禁止普通用户修改时间。

7. **首次运行默认测试模式** — 切记正式部署前关掉。

## 十四、卸载

1. 退出程序（托盘右键 → 退出；看门狗可能把它拉起来，先在设置里关掉看门狗）
2. 删除任务计划程序里的自启项
3. 删除程序目录
4. 删除数据目录：`C:\ProgramData\ClassroomBreakLock`
5. 从 U 盘里删掉 `breaklock.key`（如果你想回收那支 U 盘）
